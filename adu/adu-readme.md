[Here's the ADU sheet](https://docs.google.com/spreadsheets/d/1fbqcFtL_j4_0tGAymnpUYsjYEChAAUXwpWuInqHN-kg/edit?gid=1181835581#gid=1181835581)! I'll keep this document updated as needed. DM me on Discord with the email address you use for Google Sheets if you don't have edit perms.

There's a separate tab for every major competition (CTL, CTM ME, CTM DM), as well as regionals and miscellaneous competitions. Here's what's currently covered:
- CTWC majors (CTWC, JNC, Genesis) - full gold brackets
   - CTWC DAS is also a major, but they don't do silver/bronze brackets, instead opting for one large double-elimination flat bracket. Some of this has to be discarded, and what's included will be a bit of a judgement call. More matches should be included than a normal regional.
- CTWC regionals - Always include semis and finals; earlier rounds should also be included if a good chunk of the players are CTL Div 2+ / CTM Gold caliber (i.e. you see their names pretty frequently in the ADU). You probably shouldn't include matches with players who aren't comfortable on 18, but it's ok if some not-quite-as-good players get listed. It's really up to you.
   - Double-elimination tournaments are kinda a pain; I would suggest skipping ahead to the matches between ranked players in the lower bracket.
- CTM ME & DM - full gold brackets
- CTM STM - semis & finals
- CTL - all div 1 and 2 matches, 1/2 playoffs, and championship playoffs
- 1 Day - single-elimination phase (even if high-level players meet in the Swiss stage, streaming to the Pumpyheart twitch channel can be a bit inconsistent)
- I told the CTBW and CTap folks that they need to keep their own tabs updated if they want to appear in the ADU, so don't worry about those too much. I'll probably say the same about Gauntlet if that starts back up again; it's a bit hard to keep track of.

You'll be editing columns A-J on the sheet. (The Regional and Misc tabs have an extra column to denote the event, so those go up to K, and everything in the following list is offset by one.)
- **Round (Column A)** - for CTL and CTM, these follow a pretty specific format, so just follow what's already there. Other events can be a bit messier; just put something in the box that makes sense and I'll change it later if I need to. If the event uses a specific match numbering system, use that.
- **Player names and PP rankings (Columns B-E)** - write the players' Elo names in all caps. Look them up [here](https://docs.google.com/spreadsheets/d/1NUwqOotckIdSRH2FdfhBRHPU84N6EaRBM9BDkx5nDkU/edit?gid=1766338588#gid=1766338588) in columns D and F, and their corresponding [Premiere Poll rankings](https://premierepoll.com/) in columns C and E.
   - If the player's Elo name is not well-known in the community and doesn't match up with the name they're using for the event, you can give an alternative name in partentheses (e.g. DIVCASTE (BIG DAVE)). In limited circumstances, we'll use a name different from the Elo name, but I'm way more comfortable if they line up, so we'll coordinate with Anpu and the match database team to see if we can get a single name used across the community.
   - Assume for now that the PP rankings are the ones for the month that the match took place. If the match happened on April 1 and the April rankings are out, use those, even though they probably didn't come out until after the match.
   - For upcoming matches, put the player with the better PP ranking on the left. (For nonranked players, it doesn't really matter, but I normally use tournament seed or Elo ranking.) For completed matches, the sheet should automatically switch the names so that the winner appears on the left.
- **Time and Time Zone (Columns G-H)** - Put the date and time of the match, and which time zone you're giving the time in according to UTC.
   - For CTM, get the times for upcoming matches from the Discord event tab.
   - For CTL, use the upcoming-supershows channel. The 1/2 playoffs might be listed in upcoming-matches instead. Don't worry about Div 2 matches that aren't superstreamed before they happen; afterward, you can find the times and results on the [CTL standings site](https://ctlscoreboard.herokuapp.com), and get the VOD link from the #reporting channel.
   - If a match is part of a longer CTM or CTL show, only put the time for the first match, leaving the rest blank. The spreadsheet will add the words "to follow". For CTL, I usually put the time the show starts even if it includes matches below Div 2 that don't appear in the ADU sheet.
   - Times for completed matches don't appear in the ADU, but I like to include them anyway, since some folks use the ADU sheet for putting together their Premiere Poll rankings. You can get them from the [Match Database Sheet](https://docs.google.com/spreadsheets/d/1Rw1XT90YD8HvYN4JS0Ba1tgkp7UlrG4ksPuP4Yc4SNM/edit?gid=1434393158#gid=1434393158).
- **Score (Columns I-J)** - What it says on the tin. Column I corresponds to the player in column D, and column J to column F. The spreadsheet automatically switches the names if the player on the right won.
- **Link (Column K)** - Put a timestamped link to the VOD. Usually we use the Twitch video, but YouTube is also ok if it exists.
   - Getting the timestamp is the most time-consuming part of the process, so let me know if you have a hard time keeping up.

Once a CTL or CTM match has time information and/or results, move the spreadsheet column above the solid black column. There are also columns separating different editions of the same event, so keep that in mind as well.
